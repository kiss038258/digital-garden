厦门五通码头入境 一页通关速查表（2026最新完整版）

適用：金門→厦门五通码头入境  
規則：超申報線需主動走紅色通道申報

  

一、海产干货｜税率13%

項目｜內容

- 干贝

- 单次免税上限：1.2kg
- 15天二次入境：0.6kg
- 申报门槛：＞1.2kg
- 备注：需原厂密封包装

- 鲍鱼干

- 单次免税上限：1.2kg
- 15天二次入境：0.6kg
- 申报门槛：＞1.2kg
- 备注：禁止散装无标

- 鱼翅

- 单次免税上限：1.2kg
- 15天二次入境：0.6kg
- 申报门槛：＞1.2kg
- 备注：总量合计≤3.6kg

- 无菌罐头燕窝

- 单次免税上限：1.2kg
- 15天二次入境：0.6kg
- 申报门槛：＞1.2kg
- 备注：散装/鲜燕窝禁止

原版补充：

- 总量不可超过3.6kg
- 散装燕窝、新鲜燕窝全面禁止
- 必须原厂密封

  

二、农产干货｜税率13%

項目｜內容

- 食米 / 熟花生 / 熟蒜头 / 干金针 / 干香菇

- 单次免税上限：1kg
- 15天二次入境：0.5kg
- 申报门槛：＞1kg

禁带：

- 生花生
- 生蒜头
- 新鲜蔬果
- 各类植物种子
- 生鲜菌菇

  

三、肉蛋乳加工品｜全境禁止

項目｜內容

- 禁止品类：

- 肉松、肉干、香肠、腊肉
- 牛肉干、猪肉脯
- 皮蛋、咸蛋
- 鲜奶、奶粉、奶酪、炼乳

规则：

- 无任何例外
- 查获直接没收并处罚

  

四、茶叶｜税率10%

項目｜內容

- 15天二次入境：禁止携带
- 2–5kg：需征税
- ＞5kg：判定商业用途，禁止携带
- 必须原厂密封＋正规中文标签

  

五、药品｜税率13%

項目｜內容

1️⃣ 非处方药（感冒药/胃药/止痛药）

- 单种≤12盒
- 总量≤36盒
- 二次入境减半
- 超量需申报

2️⃣ 普通处方药

- 无处方：≤2个月用量
- 有处方：≤6个月用量
- 二次入境：仅7天用量
- 必须携带处方＋病历

3️⃣ 禁止药品

- 麝香、鹿茸、犀牛角、象牙
- 安眠药、麻醉药、精神类药  
    👉 一律禁止

  

六、烟酒（厦金航线）｜税率50%

項目｜內容

- 台湾高粱酒

- 免税：6瓶（≤4500ml）
- 当日多次往返：禁止
- ＞6瓶需申报

- 其他酒类

- 免税：2瓶（≤1500ml）
- ＞2瓶需申报

- 香烟

- 免税：200支（1条）
- ＞1条需申报

  

七、日用品｜税率20%

免税规则：

- 大陆居民：≤5000元
- 境外访客：单件≤2000元

申报门槛：

- 单件＞2000元 或 总额＞5000元


容量＋数量限制（重点）

- 洗发水/沐浴露/护发素
- ≤1000ml/瓶
- 单款≤3瓶
- 总计≤10瓶

- 身体乳/护手霜
- ≤500ml
- 总≤15件

- 洗面奶
- ≤200ml

- 喷雾
- ≤150ml
- 大容量易被扣

- 牙膏
- ≤200g
- ≤6支

- 香皂
- 无重量限制（不可整箱）

- 面膜/精华/套装
- 仅限自用，不可大量囤货

硬性要求：

- 必须原厂未开封
- 大量同款＝商业带货


八、3C家电/服饰｜税率20%

項目｜內容

- 手机/平板/相机：≤3台
- 大型家电：≤1台
- 衣物/包包：合理自用数量

申报：

- 超5000元部分征20%税

禁带：

- 二手废旧电器
- 三无产品


九、书籍印刷品｜免税

項目｜內容

- 自用≤50本

禁带：

- 色情
- 暴力
- 邪教
- 危害国家安全
- 盗版资料


十、现金＋黄金（反洗钱）

項目｜內容

- 人民币

- ≤20000免申报
- ＞20000需申报

- 外币

- ≤5000美元免申报
- ＞5000需申报
- ＞10000需说明来源

- 黄金

- ≤50g免申报
- ＞50g需申报
- ＞500g需央行批文

  

十一、15天多次入境规则

項目｜內容

- 干货/农产/中药材  
    → 第二次起减半
- 茶叶/烟酒  
    → 第二次起禁止
- 处方药  
    → 第二次仅7天用量
- 肉蛋乳  
    → 全程禁止
